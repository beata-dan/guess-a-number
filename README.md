# Guess the Number 

Guess the number is a simple browser game built using HTML, Bootstrap and JavaScript. The game starts with the computer picking a random number between
1 and 100. You then try to guess the number with a few hints 😉.


## Usage & How To Play

### Usage
- Save game.html and game.js to your local device
- Navigate to the game.html file on your local device and double click on it to open it in your browser


### How To Play
1. The computer will pick and random number between 1 and 100 as soon as you load into the browser
2. Type your first guess into the input box and click **guess**
3. Read the hint to narrow your guessing down:
   - "Too Low!" - try a higher number
   - "Too High" - try a lower number
4. Using the hints you can keep guessing until you find the correct number
   **try to do it in as few attempts as possible!**
5. When you have guessed the right number click **New Game** to play again with another randomly generated number.
